# Математические симуляции и алгоритмы обработки графики на Python
Сборник моих пет-проектов, посвященных визуализации математических процессов, фракталов и базовых алгоритмов компьютерного зрения (Computer Vision). 

В проектах минимизировано использование высокоуровневых готовых решений, основная логика вычислений и алгоритмы написаны вручную.
## 🛠 Содержимое репозитория
*   **`sierpinski_triangle.py`** — Генерация фрактального треугольника Серпинского с использованием «игры хаоса». Реализована кастомная процедурная покраска пикселей на основе нормализованных координат для получения плавных градиентов.
*   **`galton_board.py`** — Симуляция доски Гальтона (Galton Board) для демонстрации центральной предельной теоремы и нормального распределения. Включает алгоритм просчета рикошетов шариков и кастомный рендер гистограммы прямо в консоль (без использования тяжелых графических библиотек).
*   **`mandelbrot_set.py`** — Визуализация множества Мандельброта. Математические расчеты глубины фрактала реализованы с использованием модуля `decimal` для сохранения высокой точности (`getcontext().prec = 30`).
*   **`image_convolution.py`** — Самостоятельная реализация алгоритма свертки изображений (ядро сверточных нейросетей, CNN). Программа выполняет паддинг (`np.pad`), проход скользящим окном по каналам изображения с заданным шагом (stride) и нормализацию карты активации.
*   **`custom_neural_network.py`** — Самописная полносвязная нейросеть (архитектура автоэнкодера) для сжатия и восстановления изображений. 
    *   **Реализовано вручную на NumPy:** Алгоритм обратного распространения ошибки (Backpropagation), вычисление градиентов, шаг оптимизации весов (Gradient Descent) и расчет среднеквадратичной ошибки (MSE).
    *   **Математические особенности:** Инициализация весов по методу Кайминга (He Initialization) для предотвращения затухания градиентов, кастомная функция активации LeakyReLU (`f(x)`) с поддержкой утечки `alpha = 0.01` и её аналитическая производная (`df(x)`).
    *   **Визуализация:** Сеть сохраняет пошаговый процесс своего обучения, преобразуя выходы скрытых слоев обратно в RGB-изображение на каждой эпохе через PIL.
## 🚀 Используемый стек*   Python 3.x*   **NumPy** (матричные вычисления, оптимизация массивов)*   **Pillow (PIL)** / **Imageio** (вывод результатов вычислений в файлы изображений)
